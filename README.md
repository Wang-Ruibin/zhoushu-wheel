# 咒术转盘 · 纸张版（本地离线，双击即用）

一个参考「咒术转盘」设计的抽奖转盘网页小程序，整体是**宣纸 / 手绘**质感。**双击 `index.html` 就能用**，不需要联网、不需要安装、不需要服务器。
所有数据保存在本机浏览器里（localStorage），可以自己增删改转盘和选项、拖拽搭分支流程。

---

## 1. 打开方式

| 场景 | 做法 |
| --- | --- |
| 电脑 | 双击 `index.html`（推荐 Edge / Chrome） |
| 手机 | 把 `index.html` 发到手机（微信「文件传输助手」等），用浏览器打开；或放到任意静态站点/局域网服务上访问 |
| 加到主屏幕 | 手机浏览器菜单里选「添加到主屏幕」，就是一个全屏小应用，返回手势也能逐层退面板 |

> 单文件、零依赖：整个程序就只有 `index.html` 一个文件，拷走即用（样式在 `app.css`，程序在 `js/` 里 —— 都放在同一个文件夹内一起拷）。

## 2. 转盘数据文件（每个转盘一个文件）

`转盘/` 文件夹里**每个转盘一个数据文件**，双击打开 `index.html` 时会自动读取 —— 改文件、刷新网页即可生效。

```
咒术转盘/
├─ index.html        ← 双击这个打开
├─ app.css           ← 样式
├─ js/               ← 程序（按顺序加载的几小段，别改顺序）
│   ├─ _ns.js  util.js  core.js  icons.js  sound.js  spin.js  multi.js
└─ 转盘/
   ├─ _index.js                 ← 清单：决定转盘顺序（也是「按列表顺序串联」的顺序）
   ├─ 01-穿越后的初始身份.js
   ├─ 02-穿越后的时间点.js
   ├─ 03-穿越后的地点.js
   ├─ 04-穿越后的年龄.js
   ├─ 05-穿越后的性别.js
   ├─ 06-穿越后的颜值.js
   ├─ 07-道德水平.js
   ├─ 08-穿越后的术式天赋.js
   ├─ 09-穿越后的金手指.js
   └─ 10-最终结局.js
```

> 想改程序的话：`js/_ns.js` 建命名空间、`js/util.js` 是工具与配色、`js/spin.js` 是旋转与物理效果、
> `js/sound.js` 是音效、`js/multi.js` 是多面转盘的判定逻辑，其余逻辑都在 `index.html` 里的那段脚本里。
> 改完跑一下 `node _dev/run.js` 检查有没有弄坏东西。

单个文件里就是一份 JSON，直接用记事本改：

```js
/* 咒术转盘 · 单转盘数据文件
   转盘名：穿越后的初始身份
   next 写「转盘名字」表示下一步去哪个转盘；写 "结束" 表示流程到此为止；不写就留在本盘
   weight 是权重（决定扇区大小与概率），留空默认 1；color 可写 "#B23A2F" 固定扇区颜色 */
window.__ZW_REGISTER({
  "name": "穿越后的初始身份",
  "next": "穿越后的时间点",
  "removeAfterPick": false,
  "options": [
    { "label": "咒术师" },
    { "label": "咒灵", "next": "最终结局" },
    { "label": "五条悟", "weight": 3, "color": "#B23A2F" }
  ]
});
```

| 字段 | 说明 |
| --- | --- |
| `order` | 这个转盘排第几位（1 起）。**网页上改顺序后会写回这里**；手改这个数字也能改顺序 |
| `name` | 转盘名字 |
| `next` | 默认下一站：写别的**转盘名** / `"结束"` / `"留在本盘"`；不写＝留在本盘 |
| `branch` | `true` = 这是**分支转盘**（不进默认顺序，只能被选项分支指到），详见第 6 节 |
| `removeAfterPick` | 抽中后是否把该选项移出转盘 |
| `options[].label` | 选项文字 |
| `options[].weight` | 权重（扇区大小＝概率），默认 1 |
| `options[].color` | 固定扇区颜色，不写就跟随主题配色 |
| `options[].next` | 这个选项抽中后去哪个转盘（优先级高于转盘的 next） |

**为什么数据文件是 `.js` 而不是 `.json`**：双击打开（`file://`）时，浏览器禁止网页 `fetch` 本地 json（CORS 限制），但允许 `<script src>` 加载本地 js —— 所以文件内容是「JSON + 一行注册调用」，既能双击直接读，也照样可以用记事本编辑。若你更想要纯 `.json`（给别的工具读），说一声我再出一套。

**顺序写在哪儿**（三处都有，改顺序时一起更新）

1. 每个文件里的 `"order": N` 字段，以及文件头注释「顺序：第 N 位」
2. 文件名前缀 `01-` `02-` …（跟着新顺序重命名，旧的会被清掉）
3. `_index.js` 头部注释里的「当前顺序」列表 + 数组本身的排列

所以你在网页「转盘」页拖动排序后，只要授权过文件夹，这些信息就会自动跟着变；反过来说，你直接改文件里的 `order` 数字、再点「从文件重新读取」，网页顺序也会跟着变。

**网页改动 ↔ 数据文件，两边怎么同步**

| 场景 | 行为 |
| --- | --- |
| 在网上增 / 删 / 改（选项、转盘、顺序、分支…） | **立刻存进浏览器**（刷新、关掉都不会丢，也不会被文件覆盖） |
| 授权过「转盘」文件夹（设置里点一次「保存回文件夹」选目录） | 之后**每次改动 900ms 后自动写回文件**；删掉的转盘，它的文件也会被自动清掉 |
| 没授权时 | 改动只存在浏览器里，会提示一次「去设置点『保存回文件夹』授权」，不会丢数据 |
| 想用文件覆盖网页（比如你手改了 .js 文件） | 点「从文件重新读取」 |

| 按钮 / 开关 | 作用 |
| --- | --- |
| 改动后自动写回「转盘」文件夹 | **默认开**。授权过目录后，改动自动落到数据文件上 |
| 保存回文件夹 | 选一次目录并立刻全量写回（Edge/Chrome 支持；不支持就退回逐个下载） |
| 从文件重新读取 | 用「转盘」文件夹里的内容覆盖网页上的转盘（会先确认） |

> 第一次打开（浏览器里还没有数据）时，会自动用「转盘」文件夹的内容播种。
> 新增转盘：在网页上新建，或照抄一份数据文件、改名，再把文件名加进 `转盘/_index.js`（一行），然后点「从文件重新读取」。
> 读不到文件夹也不会报错（例如只把 index.html 拷到手机上），会自动退回页面内置的那份数据。

## 3. 界面说明（对照你给的截图）

```
┌──────────────────────────────────┐
│ 咒   ☰  穿越后的初始身份  ⌄        │ ← 印章 + 胶囊：点这里切换转盘
│ ⟲  初始身份·咒术师 › 时间点  → …  │ ← 流程条（走分支流程时出现，闲置会收起）
│                                  │
│              咒骸                 │ ← 抽奖结果（点一下打开操作面板）
│                                  │
│            ╭────────╮            │
│           ╱   转盘    ╲           │ ← 点转盘 = 旋转
│            ╲          ╱          │
│            ╰────────╯            │
│                                  │
│   ⚙︎                                     ✎   │ ← 左：设置与记录 右：编辑选项
└──────────────────────────────────┘
```

- **顶部印章 + 胶囊**：左边「咒」是装饰印章；点胶囊直接打开**「转盘」页** —— 一页里就能切换转盘 + 改名 / 排序 / 复制 / 删除，**点转盘名字**就进它的选项内容管理。
- **中间大字**：楷体显示抽中的结果；旋转过程中**实时跟随指针**——转盘转到哪一块，这里就显示哪一块，文字超过 7 个字会自动缩小，停下即定格。
- **点结果**（不是旋转中）会打开「本次结果」面板：复制结果 / 去下一站 / 再抽一次 / 从转盘移除该选项。
- **转盘**：指针固定在 12 点方向，中心是一个**很短的小针尖**——颜色与中心圆盘一致（浅色=米白、深色=墨黑），外面配一圈极细墨线保证在任何扇区上都看得清，尖头只探出约 0.065R（针尖高度 0.22R，初版是 0.46R）；外圈是**手绘墨线**（固定种子生成，不会随帧抖动）；扇区从 12 点方向顺时针排列。
- **左下 ⚙︎**：直接打开管理面板的「设置」标签；**右下 ✎**：直接编辑**当前转盘**的选项内容（等同于在「转盘」页点它的名字）。
- 旋转：**点转盘** 或按 **空格键**（关掉面板时）；**Esc** 逐层返回。原本的「点击旋转」按钮已经删掉，底栏只留设置/编辑两个圆钮。

每次抽完会弹出提示条「抽中：xxx」，右侧有「复制」按钮；开了「抽中后移除」还会顺带把该选项从转盘上删掉。

## 4. 页面层级与返回逻辑

整个应用是**一个中枢 + 一个返回栈**，没有交叉的入口：

```
主页 ──┬─ 转盘（全屏列表：选转盘 + 改名/排序/复制/删除都在这一页）
       │      └─ 选项内容（某个转盘的详情子页：点转盘名字进来，返回即回列表）
       │              └─ 批量编辑（子页）
       │              └─ 跳转目标选择（子页）
       ├─ 设置 / 记录（同一个面板的其余标签）
       └─ 本次结果（底部小面板）
```

| 操作 | 行为 |
| --- | --- |
| ⚙ / 顶部胶囊 | 直接落到「设置」/「转盘」标签，不用再层层点进去 |
| ✎（右下） | 直接编辑**当前转盘**的选项内容，等同于在列表里点它的名字 |
| 面板里切标签 | 也算一层：返回会先回到上一个标签，再关面板 |
| 选项内容页 | **不占标签位**，只能从「转盘」列表点名字进入；返回必定回到那个列表 |
| 浏览器后退 / 安卓返回手势 / Esc | 与界面返回走同一条逻辑：**逐层退**，不会再一按就退出网页 |
| ✕ 关闭 | 一次性清掉本次压入的所有历史条目，之后按返回键不会出现「按了没反应」的空跳 |
| 滚动位置 | 改个开关、拖一次连接后，长列表停在原处，不会跳回顶部 |

## 5. 统一管理转盘与内容

管理面板 3 个标签：**转盘 / 设置 / 记录**；「选项内容」是点某个转盘名字进去的详情子页。

**转盘**（点顶部胶囊直达；这一页把「选择转盘」和「管理转盘」合在了一起）

每一行长这样：

```
● 穿越后的初始身份           [分支]  9 项  ›     ← 点这一行 = 进它的「选项内容」管理
  [使用中]  [✎ 改名]  [↑]  [↓]  [复制]  [删除]      ← 操作区：切换 / 改名 / 排序 / 复制 / 删除
```

- **点转盘名字**（整行）→ 直接进这个转盘的**选项内容**页；返回就回到这个列表
- `[分支]` → 把它标成**分支转盘**（红色 = 已标记），详见第 6 节
- `切换` / `使用中`：设为首页正在用的转盘（红色高亮那行就是当前的）
- `✎`：改名（会同步写进数据文件的转盘名）
- `↑` `↓`：调整顺序（这条顺序也是「按列表顺序串联」流程的依据）
- `复制`：做同系列转盘很方便；`删除`：至少保留一个
- 颜色小点：这个转盘第一个选项的颜色，一眼区分
- 「＋ 新建转盘」新建后自动跳到选项编辑

**选项内容**（在「转盘」页点转盘名字进来；右下 ✎ 可直达当前转盘）

- 顶部「编辑中」那一行可以下拉切换要编辑哪个转盘，右边的 `✎` 直接给这个转盘改名
- 每行：`色块`（点开改单色 / 点 `A` 恢复跟随主题）· `文字` · `权重` · `删除`
- 工具条：`添加选项` / `批量编辑` / `打乱顺序` / `重新配色` / `清空`
- 「抽中后从转盘移除该选项」开关：适合抽签、点名、抽人分组

**批量编辑**：一行一个选项，可用 `名称*权重` 写权重，例如

```
五条悟*3
虎杖悠仁
伏黑惠*2
钉崎野蔷薇
```

`*`、`×`、`x`、`,数字` 都识别为权重，不写就是 1。选「覆盖当前选项」或「追加到末尾」。

**权重怎么起作用**：扇区面积按权重比例分配，权重越大扇区越大、概率越高；填 `0` 表示停用（不显示、不会被抽中）。所以「所见即所得」——转盘上指针停在哪块，就是抽中哪块，不存在暗箱概率。

每个选项下面还有一行 `→ 跳转目标`（见下一节）：点它可以单独指定「这个选项抽中后去哪个转盘」，不设置就跟随该转盘的默认下一站。

## 6. 分支流程：抽完自动跳下一个转盘


打开方式：**各个转盘的「选项内容」页**里设置（每个选项下面那行 `→`，以及页面顶部的「默认下一站」）；流程的整体开关在「设置」页。

**怎么设目标**：在「选项内容」页里

1. **选项级**：每个选项下面那行 `→ …`，点开从列表里选「抽到这个就去哪个转盘」（也可以选「留在本盘 / 流程结束」）。
2. **转盘级**：页面顶部的「默认下一站：…」那一行，设这个转盘其余选项的下一站。
3. **不设也行**：都没设时跟着「转盘」页的**列表顺序**走 —— 所以只要排好顺序，流程就能一路走下去。

**三级优先级：选项目标 → 默认下一站 → 列表顺序**

| 位置 | 含义 |
| --- | --- |
| 选项自己的 `跳转目标` | 最高优先：某一个选项抽中就固定去某个转盘（例：初始身份里抽到「咒灵」→ 直接进「最终结局」） |
| 转盘的 `默认下一站` | 其余选项都走这里（例：初始身份 → 时间点） |
| **都没设** | **跟着「转盘」页的列表顺序走**（跳过分支转盘）——所以列表顺序就是默认流程，中间漏设也不会卡住 |
| 排在列表最后 + 都没设 | 流程结束 |
| `流程结束` / `留在本盘` | 显式收尾 / 显式原地不动（想停在原地就得写这一项） |

界面上会直接告诉你实际会去哪儿：「选项内容」页顶部的「默认下一站」行、以及每个选项下面那行都写着实际目标（例如「跟随列表顺序 → 穿越后的初始身份」）。

**分支转盘（不在默认顺序里的插曲）**

在「转盘」页点行里的 `[分支]` 就能把某个转盘标成**分支转盘**（红色标记）。它的规则是：

1. **不进默认顺序**：`按列表顺序串联` 会跳过它；它自己那条「默认下一站」会被清空，别人也不会指到它。
2. **只能靠分支进入**：只有某个转盘的**选项跳转目标**指向它，才会走到它（在「分支」页给选项挂目标，或在「选项内容」页点每个选项下面那行 `→`）。
3. **转完接着「原转盘的默认顺序」**：如果它抽中的那个选项**没有**单独设跳转目标，就按下面顺序找下一站 ——
   - 原转盘的**默认下一站**（若设了且不是它自己）
   - 没设 / 指向自己 / 指向另一个分支转盘 → 顺着**列表顺序**往下找下一个普通转盘（所以不会卡在原地，也不会自己跳回自己）
   - 原转盘明确写了 `结束` → 流程结束

```
初始身份 ──默认──▶ 时间点 ──默认──▶ 地点 …      （主线，分支转盘不在其中）
   └ 抽到「咒灵」──▶ 〔死亡结局·分支转盘〕
                        ├ 抽到「被宿傩夺舍」──▶ 最终结局      （选项自己设了目标）
                        └ 抽到别的 ──▶ 回到「初始身份」的默认下一站 = 时间点
```

可以套多层（分支转盘里再拐进另一个分支转盘），结束后会一层层往外找，直到接回最近的主线；「流程条」上能看到这一路的轨迹。

**防死循环**：万一配置成了环（比如某个转盘的默认下一站指回它自己），连续 12 次都停在同一个转盘时会**临时暂停**自动跳转，流程条上出现 `⏸ 已暂停 · 继续`；点它、或者手动切换转盘、点「重来」都会恢复。**不会**像以前那样把「自动跳转」这个开关永久关掉。

**流程的开关**在「设置」页顶部：使用分支流程 / 抽中后自动跳转 / 停留时长 / 跳转后自动旋转 / **中途走到维度图时弹出来看一眼** / **维度图停留** / 流程结束时弹出属性维度图，还能设置**起点转盘**和「清除所有连接」。

**走到维度图那一位会怎样**

如果某个位置放着一张属性维度图（见第 7 节），流程走到那儿时会：

1. 抽完先等 **0.65 秒**（让中奖动效播完）→ **自动弹出那张维度图**
2. 停留 **3.4 秒**（设置里「维度图停留」可调 1–15 秒），提示条上写着还剩多久，也可以点「现在继续」立刻走
3. 自动收起 → **接着跳到下一站**

不想被它打断：关掉「中途走到维度图时弹出来看一眼」就行（中途弹图和**流程结束时**那张图是**两个独立开关**）。
手动模式（关掉「抽中后自动跳转」）时也不会自动弹 —— 免得抢注意力。
中途你自己把图关掉 / 已经开着别的面板，流程都会照常继续往下走，不会卡住。

**两个开关各管一件事（互不影响）**

「分支」页顶部是三段式：总开关 + 两个缩进的子开关，下面还有一行实时显示当前模式。

| 开关 | 作用 | 默认 |
| --- | --- | --- |
| 使用分支流程 | 总开关：关掉就完全不介入（不记路径、不跳转） | 开 |
| 抽中后自动跳转下一站 | 抽完自动走到下一站 | 开 |
| 跳转后自动旋转下一个转盘 | 跳过去之后**再自动转一次**，一路连转 | **关** |

所以默认状态就是「**只跳不转**」：跳到下一站后停下、结果区复位成 `？`，等你点一下转盘（或按空格）。
模式提示会实时显示四种状态：只跳不转 / 一路自动连转 / 手动模式 / 分支流程已关闭。

**跑起来是什么样**

- 抽完 → 顶部出现流程条：`⟲ | 初始身份·咒术师 › 时间点 | → 术式天赋`，最后一个红色胶囊是当前所在转盘，右边 `→ xxx` 是下一站。
- 流程条闲置 7 秒会自动收起成一个小胶囊（`初始身份 · 第 2 步`），点一下重新展开，避免一直占着主界面。
- 停留 1.6 秒（可调 0.4–5 秒）后自动跳到下一站，结果区复位成 `？`；再点一下 `→ xxx` 可以立刻前往。
- 只有额外打开「跳转后自动旋转下一个转盘」，整棵流程树才会自己一路抽到底，适合做连续剧情/连抽。
- 流程条上的历史胶囊可以点——**回到那一步重来**（后面的路径会被截掉）；最左边 ⟲ 是回到起点重新开始。
- 关掉「抽中后自动跳转下一站」就变成手动模式：只提示下一站，你自己决定什么时候走。

## 6.5 多面转盘：同一个转盘，按之前的结果换内容

**它解决什么**：有些转盘的描述得看前面的结果才说得通。
比如「声望」——道德高的时候 EX 是**超凡入圣**、S 是**家喻户晓**；
道德低的时候 EX 变成**婴儿止啼**、S 变成**臭名昭著**。

**和分支转盘的区别**（这俩最容易混）：

| | 分支转盘 | **多面转盘** |
| --- | --- | --- |
| 改变什么 | **流程跳到哪** | **这个转盘自己显示什么** |
| 在默认顺序里吗 | 不在（只能被选项跳转指到） | **在**，位置随便换，和普通转盘一样 |

**怎么用**：

1. 在「转盘」页，点某个转盘那行的「**多面**」标记 → 它变成多面转盘（会自动猜一个"按哪个转盘分面"，猜错了能改）
2. 进「**管理面 / 条件…**」，先在上面选**按哪个转盘分面**（比如「道德水平」）
3. 「**加一个面**」，设条件：选「等级 ≥」，再点 `A` → 这个面就管"道德 A 及以上"
4. 在面列表里点「**内容**」编辑这一面的选项（普通转盘那套编辑方式：单条改 / 批量 / 拖动排序都行）
5. 再加一个面，条件设「等级 ≤ B」，内容填低道德那套
6. 最下面的「**兜底面**」= 面都没命中时用的（比如「道德水平」还没抽过）。它也是普通的那套 `options`

**规则**：
- 从上往下找**第一个**命中的面 → **面的顺序就是优先级**（用 ↑↓ 调）
- 判定用的是**叠加成长之后**的结果 —— 成长把道德从 B 抬到 A，声望就自动切换到高道德那一面
- 那个盘**还没抽过** → 等级类条件一律不命中 → 落到兜底面
- 抽奖时用的是**当前命中那一面**的选项，不是兜底面的

**条件能写哪些**（面管理里点「改条件」）：

| 条件 | 例子 | 意思 |
| --- | --- | --- |
| 等级 ≥ | `A` | 抽到的等级是 A 或更高（按 `E- E D C B A S SS SSS EX` 排） |
| 等级 ≤ | `B` | 抽到的等级是 B 或更低 |
| 等级 = | `S` | 正好这一档 |
| 结果 = | `S（乐善好施）` | 抽到的文字完全一样 |
| 结果包含 | `乐善` | 抽到的文字里含这几个字 |
| 其他情况 | — | 相当于「否则」，一般放最后一条 |

**流程条上**当前转盘是多面转盘时，会额外标出它此刻用的是哪一面（比如 `声望 · 等级 ≥ A`）。

**手改数据文件**也行，格式见 `转盘/*.js` 里的注释：

```js
"multi": true,
"faceBy": "道德水平",                       // 按哪个转盘分面（写转盘名）
"faces": [
  { "when": { "type":"gradeAtLeast", "value":"A" }, "options": [ { "label":"EX（超凡入圣）" } ] },
  { "when": { "type":"gradeAtMost",  "value":"B" }, "options": [ { "label":"EX（婴儿止啼）" } ] }
],
"options": [ { "label":"（兜底）默默无闻" } ]
```

## 6.6 成长转盘怎么写

选项文字里写「**属性名+数字**」就会给对应属性升 N 级（沿 `E- E D C B A S SS SSS EX` 上移，EX 封顶）。

- **名字写法很宽松**：转盘**全名**（`咒力操纵+1`）、**名字的一部分**（`咒力+1` → 咒力总量）、
  或者内置简称（`体术+1` → 体术水平、`咒操+1` → 咒力操纵、`评级+1` → 等级评定）
- 名字里带括号的也能写全：`体质（基础体质）+1`
- 一个选项里可以带多个：`我悟了！（阴阳术+1）（剑术+2）`
- **加新属性不用改任何设置** —— 只要成长文字能对上某个转盘的名字就自动生效
- ⚠️ 写的名字**对不上任何转盘**时，转了也不会升（不报错）。
  这种情况**「选项内容」页底部会用朱砂字提示**「这些选项里的成长对不上转盘」，照着改就行
- 数字型属性（如 `3个`）按该盘自己的选项递增；`不会` 当成 0（所以 `不会+1` 得 `1个`）
  · 但 `没有 / 有几个 / 很多` 这种**没有数字**的选项不会递增 —— 想让它长就写成数字
- 文字型 / 数字型的盘**不进属性维度图**（维度图只看等级标签）

## 7. 属性维度图（等级 → 雷达图）

带 **E- / E / D / C / B / A / S / SS / SSS / EX** 这类等级的转盘会被自动识别成「属性盘」，
把每个属性盘**最后一次**抽到的等级汇总成一张雷达图（分值 = 等级 × 10）。

**随时都能建**：不需要等属性盘抽完。在「转盘」页（或「记录」页）点「新建属性维度图」，
选一个**统计范围**——「到某个转盘为止」或「全部转盘」；把这个范围里**所有属性盘**都算进来，
**没抽到的按 0 算**。生成后这张图就**定格**、不再随转盘变化。

**它会排在哪儿**：维度图按所选范围**插进「转盘」页的列表里**（例：选「到道德水平为止」，它就排在那行后面，
左侧有朱砂色的边和一个「维度图」徽标）；选「全部转盘」的排在所有转盘之后。可以随时查看 / 删除。

**变化动画**：再新建一张时，新图会**从上一张的形状变形过来**（每根轴从旧值长到新值）；
第一次生成则从中心 0 长出来。

```
              道德水平  SS · 80
                  ／＼
    咒力效率 E-·17 ／    ＼ 穿越后的颜值 A · 60
    咒力操纵 S·70  ＼    ／ 咒力总量   EX · 100
                  ＼／
              体术水平  B · 50
        本局已抽 6 项 · 平均 63
```

- **成长会体现在图里**：成长转盘升过的级会叠加到对应属性上，两张图（不管位置怎么选）都按同一套规则算
- **面板**：只有图名、图和一个关闭按钮 —— 标签只写「转盘名 + 等级」

> ⚠️ 一个已知的语义细节：成长是**按本轮累计量**算的，**不区分成长发生在第几步**。
> 所以把图放在成长转盘**之前**，它的数值**也会**跟着涨（等于"本轮到目前为止，含所有已获得的成长"）。
> 如果你希望它严格定格在"那一刻"，说一声，改起来要动存档结构。

- **入口只有一个**：管理面板 →「记录」页 → 「新建属性维度图」/ 下面已生成的列表（点名字查看、🗑 删除）
- **流程走到它那一位会自动弹出来**：抽完等 0.65 秒弹出 → 停留 3.4 秒（可调）→ 自动收起 → 继续下一站。
  开关和时长都在「设置 → 流程」里（详见第 6 节末尾）
- **打开后就是一个干净的雷达图**：只有图名、图和一个关闭按钮 —— 标签只写「转盘名 + 等级」，不显示数字
- **旋转时的物理效果**：在「设置」页选，五种可选；实现方式是每帧给转盘容器加一个 `transform`，幅度随进度收敛，停下时带 0.34 秒过渡回正。其中 **3D滚筒** 用 `perspective(560px) + rotate3d()`：倾角每转一圈翻出去一次（24°），倾角轴以 0.45 倍速绕圈（硬币旋摆感），配合 `rotateY` 与 5% 透视缩放；**2D滚筒** 是纯平面的椭圆轨迹（横向 ±26px、纵向约 ±19px）＋轻微扭转。相位按**每秒固定圈数**推进（`FX_2D_TURNS_PER_SEC = 1.5`，配 1.35 的轻缓出），所以：① 滚动速度**跟转盘自转圈数脱钩**（转 8 圈还是 20 圈，都是约 1.4 圈/秒的节奏）；② 单帧相位只走十几度，轨迹连续顺滑（直接用自转角度会因每帧转几十度而混叠成几个固定方位，就显得又慢又跳）。想更快/更慢改那个常量即可（在 `js/spin.js` 顶部）。**3D滚筒**同理：相位也按时间驱动（`FX_3D_TURNS_PER_SEC = 1.1`，同一个 1.35 缓出），倾角、倾角轴、`rotateY`、透视缩放单帧变化都只有几度，翻起来是连续的立体翻滚（以前相位跟着自转角度走，被欠采样成乱跳的值，看着一顿一顿）。老存档里如果选过「摇摆 / 甩出」，会自动迁移成 2D滚筒 / 颠簸。
- **展示效果**：面板**居中**显示（不再是贴着底部的抽屉），图会**尽量放大**（手机上大约占屏幕高度的 3/4），标签统一排在 EX 外圈之外，不会和溢出的顶点重叠
- **删除 / 新建都在「记录」页的列表里**（图表面板里没有再放按钮）
- **动画**：首次生成时多边形从**中心 0** 长到对应分值；从第二张起，会从上一张的形状变形过来（easeOutCubic，约 1 秒）
**法轮背景**：维度图画在一座「法轮」上 —— **八根辐条**对应八个方向，**外环正好压在 SSS 值**上，
**外圈八颗小球的圆心正好落在 EX 值**上（也就是环外一格），圆心还有一颗小球；
颜色在「设置 → 法轮颜色」里单独选。每次打开维度图，法轮会**逆时针咔哒转 45°**（分 8 格、每格先快后停的齿轮顿挫感，
齿轮音来自 B 站「**魔虚罗音效素材**」[BV1KF3S62EaK](https://www.bilibili.com/video/BV1KF3S62EaK) 的 **0~3 秒**，
已转成 18KB 的 mp3 并**用 base64 内嵌进 `js/sound.js`**（仍然离线可用，没有引入外部文件请求，也没有版权文件随包分发之外的额外要求）。
解码失败或音效数据缺失时会自动退回内置的 Web Audio 合成齿轮音兜底。

- **配色**：在「设置」页的「维度图颜色」里选（朱砂 / 墨黑 / 靛青 / 赭金 / 苔绿 / 紫苑），换完立刻按新颜色重画。
- **刻度与分值**：外圈满格 = **SSS**，虚线圈 = **EX**（溢出一格）；分值 = 等级 × 10 —— E- 17、E 20、D 30、C 40、B 50、A 60、S 70、SS 80、SSS 90、EX 100；`+ / -` 也认（S+ = 73）
- **谁算属性盘**：选项里六成以上是等级标签的转盘自动计入（列表里带「属性」徽标）；也可以进某个转盘的「选项内容」页，
  用「计入属性维度图」开关强制计入 / 排除，再点「恢复自动判断」回到自动
- **取哪一次的结果**：同一轮里取这个属性盘最后一次的结果；这一轮还没抽过，就退回用最近的抽奖记录；都没有就是 0
- 等级设置会写进数据文件（`"grade": true` / `"grade": false`，自动判断时不写）

## 9. 技术实现备注

- 纯原生 HTML + CSS + Canvas 2D，无框架、无外部资源、无打包工具，可直接离线使用。
- **代码分成几小段加载**：`js/_ns.js`（建 `window.ZW` 命名空间）→ `js/util.js`（工具与配色）→ `js/core.js`（跨模块共享的运行时变量：转盘角度等）→ `js/icons.js`（图标）→ `js/sound.js`（音效与震动）→ `js/spin.js`（旋转与物理效果），其余业务逻辑在 `index.html` 里的那段脚本。
  - 用**普通 `<script>` + 一个全局对象**而不是 ES module —— 因为 `file://` 下 `type="module"` 会被浏览器的同源策略挡掉，双击就打不开了。
  - 模块之间只通过 `ZW.xxx` 来往；需要的存档数据（当前色板、音效开关等）由主逻辑**注入**进去，所以每个文件都能单独测试。
- **纸张质感**用 CSS 变量 + 一层内联 SVG `feTurbulence` 噪点（data URI）实现，不依赖任何图片文件；「手绘」靠不规则圆角（`border-radius` 八值写法）、墨色描边、双层偏移阴影和楷体标题堆出来。
- 转盘用 Canvas 绘制并做高清屏（DPR）适配；文字沿半径排布、超长自动缩字号/截断，深色扇区自动用白字；外圈与中心圈的**手绘抖动用固定种子生成**，所以每帧形状完全一致，不会闪。
- 旋转用 `requestAnimationFrame` + easeOutCubic 缓动；**先按权重抽好结果，再反推落点角度**，因此指针指向的扇区与显示结果永远一致。
- 页面层级用**单一视图栈** `NAV.stack`（栈顶即当前状态）+ History API：`navTo` 压栈并 `pushState`，`navBack` 出栈，`navCloseAll` 关闭时 `history.go(-n)` 一次性清理。界面返回、Esc、浏览器后退 / 安卓返回手势走的是同一条逻辑。
- 分支转盘用一个小**返回栈** `flow.retStack` 实现：拐进分支转盘时压入「从哪来」，转完若没设目标就弹出并接回那一层的默认下一站；进入普通转盘则清空（表示已回到主线）。带 30 层保护，配合原有的 60 步熔断，循环配置也不会卡死。
- 分支跳转用指针事件（Pointer Events）实现拖拽：阈值 8px 才开始拖（不误触滚动），半透明胶囊跟随手指，`elementFromPoint` 命中虚线框即高亮；触屏拖不动时点一下虚线框也能选，两条路都通。
- 数据存 `localStorage`（键名 `zhoushu-wheel.v1`，结构 `version:2`），导入时做字段兜底、旧格式兼容与一次性迁移（v1 的默认配色「鲜艳」自动换成「宣纸」），脏数据不会让程序打不开。
