## ✨ 功能亮点

- 🎨 **宣纸手绘风**：墨线转盘、楷体大字、纸张噪点纹理；浅色宣纸 / 深色墨夜两套外观 × 六套国风配色
- 🎯 **所见即所得**：扇区多大、概率就多高——指针停在哪儿就是抽中哪儿，没有暗箱概率
- 🔀 **分支剧情**：给选项设「抽中后去哪个盘」，抽到「咒灵」就直接坠入死亡结局盘；抽完自动跳下一站，流程条记录整条命运链，还能回到任意一步重抽
- 🧭 **属性维度图**：道德、咒力、体术……等级盘的结果汇总成画在**法轮**上的雷达图，每次出场自带咔哒 45° 转动
- 🎭 **多面转盘**：同一个「声望」盘，道德高时 EX 是*超凡入圣*，道德低时变成*婴儿止啼*
- 📈 **成长机制**：事件成长盘会把已抽到的等级往上抬，雷达图跟着一起变
- 📴 **完全离线**：整个文件夹拷走即用，数据存在本机浏览器里，支持导出 / 导入 JSON 备份换设备
- ⌨️ **无障碍**：空格旋转、Esc 逐层返回、`prefers-reduced-motion` 自动关动效、结果语音播报

## 🎮 怎么玩

### 抽奖
点转盘（或按空格）开始转，五种旋转手感随便换：平稳、颠簸、2D/3D 滚筒、收势。中间的楷体大字实时跟着指针走，停下即定格。点结果可以**复制**、**再抽一次**，或把它**从盘上移除**——拿来抽签、点名、分组正好。

### 分支流程
每个选项都能设「抽中后去哪个盘」：不设就按列表顺序自动走，设了就走专属剧情线。顶部流程条会记下你这一路的命运（`初始身份·咒术师 › 时间点 → …`），点任意一个历史节点可以回去重抽。放心乱连——连续 12 次困在同一个盘会自动暂停，不会死循环。

### 属性与成长
所有带等级（E- ~ EX）的盘自动算属性盘，随捶手一张维度图，把你的道德、咒力、体术画成雷达图；流程路过时还会自动弹出来展示 3 秒。事件成长盘抽到好事件会把你已获得的等级往上抬——成长会实时反映在图上。

### 换个玩法？
转盘管理页支持**新建 / 复制 / 拖动排序**，选项支持**批量编辑**（一行一个，`名字*权重` 直接写权重）、拖拽连线分支；「抽中后移除」适合抽签；六套配色 + 浅深外观 + 法轮颜色独立可调。更多细节见[完整功能手册](docs/zh-CN/guide.md)。

## 📦 数据在你手里

所有改动存在浏览器 localStorage，**随时导出 JSON 备份**、换设备导入。愿意的话还能授权「转盘」文件夹，让网页改动**自动写回数据文件**（一个盘一个 `.js`，记事本就能改，改完刷新生效）——为什么是 `.js` 不是 `.json`？双击打开的本地页面读不了本地 json，详见[手册第 2 节](docs/zh-CN/guide.md#2-转盘数据文件每个转盘一个文件)。

## 🛠️ 参与开发

零构建、零依赖：纯 HTML + CSS + 原生 JS + Canvas 2D，clone 下来就能动手。

```bash
git clone git@github.com:Wang-Ruibin/jujutsu-wheel.git
cd jujutsu-wheel
# 双击 index.html 即可本地运行；需要 HTTP 源时：
python -m http.server 8000
# 提交前必须全绿（297 条断言）：
node _dev/run.js
# 单跑一个测试：
node _dev/t13_multi.js
```

两条上手须知：

- `js/` 模块的加载顺序写死在 `index.html` 顶部，别乱动；模块之间只走 `ZW` 命名空间，不加新全局。
- 代码风格、测试要求、提交与 PR 规范见 [AGENTS.md](AGENTS.md)。

欢迎 issue 和 PR；[功能手册第 10 节](docs/zh-CN/guide.md#10-想要的功能可以继续加)列了一些候选功能，也欢迎你自己想加的。
